# 帧间 Zhenjian

一帧一帧，连成故事。面向电商和短剧团队的 AI 视觉创作工作台，包含两个模块：

- **电商图片**：批量导入 SKU，按套图方案为每个商品一次生成白底图、主图、场景图，支持按平台批量改尺寸、批量换风格。
- **短剧生成**：故事设定 + 角色卡 → 分镜脚本 → 关键帧确认 → 逐镜生成视频，合成 MP4 成片。

## 使用的模型

| 环节 | 模型 | 平台 | 参考成本 | 本产品定价 |
| --- | --- | --- | --- | --- |
| 电商图、关键帧、局部重绘 | **Seedream 4.0**（20260415 版） | 火山方舟 | 0.20 元/张 | 4 积分/张 |
| 分镜脚本 | **DeepSeek V4.1 Flash** | 火山方舟 | 输入 1–2 元 / 输出 4–8 元（每百万 tokens，工作日高峰时段贵一倍），一次分镜不到 0.01 元 | 2 积分/次，重写单镜 1 积分 |
| 视频 · 标准档（默认） | **Seedance 2.0 mini** 720p | 火山方舟 | 0.5 元/秒，单条 4–15 秒 | 10 积分/秒 |
| 视频 · 精品档 | **可灵 2.5 Turbo** 1080p | 可灵开放平台 | 约 2.5 元/5 秒 | 50 积分/5 秒 |

1 积分 = 0.1 元，按成本约 2 倍定价，可在 `app.js` 的 `PRICING` 里调整。火山方舟的三个模型共用一个 API Key。

> 2026-09 起火山方舟停止开通 Seedream 4.0（250828 版）、Seedance 1.0 pro-fast，DeepSeek V3.1 已于 2026-03 下线，本项目已按官方迁移建议换成上表型号。

## 给别人用：打包成解压即用的压缩包

```bash
npm run package                # 打 Mac（Apple 芯片 / Intel）和 Windows 三个包
npm run package -- mac-arm64   # 只打一个
```

压缩包在 `dist/` 里，自带 Node 运行环境，对方不需要安装任何东西：

```
帧间-<版本>-mac-arm64/
├── 启动帧间.command   Mac 双击启动（Windows 版是「启动帧间.bat」）
├── 使用说明.txt
├── app/              程序
├── runtime/          自带的 Node 运行环境
└── data/             第一次启动后生成：项目、图片、视频、密钥都在这里
```

对方的使用流程：解压 → 双击启动 → 浏览器自动打开 → 在「设置」里粘贴自己的 API Key → 开始生成。费用由各平台直接从对方自己的账户扣除。

- 打包需要在 Mac 或 Linux 上运行（用到 `tar`、`unzip`、`zip`）。Node 安装包从 npmmirror 或 nodejs.org 下载，并用官方 SHASUMS256 校验，缓存在 `.cache/`。
- 双击启动时，如果同一份数据的帧间已经在运行，会直接打开浏览器；端口被其他程序占用时自动换下一个。
- 包里没有带 ffmpeg，导出短剧时会改为逐个下载镜头。可以用 `FFMPEG_PATH` 指定 ffmpeg 位置。
- 启动脚本没有代码签名：Mac 第一次需要右键 →「打开」，Windows 可能要在 SmartScreen 里点「仍要运行」。`使用说明.txt` 里写了步骤。

## 两种运行方式

| | 演示模式 | 正式模式 |
| --- | --- | --- |
| 怎么启动 | 任意静态服务器、GitHub Pages、Claude Artifact | `npm start`（运行 `server/index.mjs`） |
| 生成结果 | 浏览器 Canvas 模拟 | 调用上表的真实模型 |

页面启动时会请求 `/api/health`，能连上后端就自动切到正式模式。首页和各模块右上角会显示「已就绪」。页面上不展示具体用的是哪家模型，出错提示也只说「生图服务」「分镜服务」「视频服务」；缺少哪个密钥只写在服务器日志里。

## 部署正式模式

需要 Node.js 18 以上。合成短剧成片还需要 ffmpeg，没装也能用，只是导出时改为逐个下载镜头。

```bash
git clone https://github.com/Qi0618/AIGC-zhenjian.git
cd AIGC-zhenjian
cp .env.example .env      # 填写密钥，见下文
npm start                 # 默认 http://localhost:8787
```

后端没有第三方依赖，不需要 `npm install`。

### 用 Docker 部署

镜像里已经装好 ffmpeg，生成的文件保存在挂载的 `data` 目录：

```bash
docker build -t zhenjian .
docker run -d -p 8787:8787 --env-file .env -v "$PWD/data:/data" zhenjian
```

### 运行测试

```bash
npm test
```

测试会启动一个本地假上游来模拟火山方舟，不需要密钥，也不会消耗额度。

### 填写密钥

推荐直接在网页左侧的「设置」里填写：粘贴 Key → 点「测试连接」→ 保存，立即生效，不需要重启。第一次打开、还没有填写任何密钥时，会自动进入设置页。

- 密钥保存在 `data/settings.json`（只有本人可读），优先于 `.env`。
- 「测试连接」只调用各平台免费的查询接口，不产生费用。
- 服务默认只监听本机（`HOST=127.0.0.1`），局域网里的其他设备连不上。要开放给其他设备访问，设置 `HOST=0.0.0.0`，并务必设置 `ACCESS_TOKEN`；没有口令时，设置页只能在本机修改。

也可以继续用 `.env` 配置（适合服务器部署）：

### 填写 .env

1. **火山方舟**：在 [火山方舟控制台](https://console.volcengine.com/ark) 创建 API Key，填到 `ARK_API_KEY`。在「开通管理」里开通 Seedream 4.0、DeepSeek V4.1 Flash、Seedance 2.0 mini。
   - 模型 ID 会随版本更新，`.env.example` 里是默认值，以控制台「模型广场」显示的为准。
   - 也可以填自建推理接入点的 `ep-xxxx`。
2. **可灵**（可选，精品档用）：在 [可灵开放平台](https://app.klingai.com/cn/dev) 创建 AccessKey / SecretKey，填到 `KLING_ACCESS_KEY` 和 `KLING_SECRET_KEY`。不填的话，视频模型里的可灵选项会置灰。
3. **ACCESS_TOKEN**：部署到公网前一定要设置。设置后打开网页要先输入口令，防止别人消耗你的模型额度。

生成的图片和视频保存在 `data/files/`（可用 `DATA_DIR` 修改）。模型返回的临时链接 24 小时就会失效，所以后端会先下载到本地再返回给页面。

### 后端接口

| 接口 | 作用 | 上游 |
| --- | --- | --- |
| `GET /api/health` | 检测后端和各模型是否已配置 | — |
| `POST /api/image` | `{prompt, images[], width, height}` → `{url}` | Seedream 4.0 `images/generations` |
| `POST /api/storyboard` | `{story, enums}` → `{shots}` | DeepSeek V4.1 Flash `chat/completions` |
| `POST /api/shot` | `{story, enums, shots, index}` → `{shot}`，重写单个镜头 | 同上 |
| `POST /api/video` | `{provider: seedance\|kling, image, prompt, duration}` → `{id}` | Seedance `contents/generations/tasks` / 可灵 `v1/videos/image2video` |
| `GET /api/video/:id` | 查询任务进度，完成后返回 `{url}` | 同上 |
| `POST /api/concat` | `{urls, durs}` → 合成后的 `{url}` | 本地 ffmpeg |

#### 实现说明

- **生图尺寸**：Seedream 4.0 要求总像素在 1280×720 到 4096×4096 之间。后端先按目标比例生成高清图，前端再精确裁成平台尺寸，比如 800×800。
- **商品一致性**：生成电商图时，SKU 原图作为参考图传给模型，并在提示词里要求保持外观和包装文字不变。批量改尺寸、改风格时，已生成的图也会作为参考图传入。
- **角色一致性**：生成关键帧时，出镜角色的参考图会一起传入。
- **局部重绘**：把当前关键帧作为参考图整张重画，再只把框选区域贴回原图，其他部分保持不变。
- **视频**：已确认的关键帧作为首帧做图生视频。Seedance 2.0 mini 支持 4–15 秒，短于 4 秒的镜头按 4 秒生成和计费。可灵只支持 5 秒和 10 秒，按 5 秒为单位计费；镜头短于成片时长时，合成时会裁到分镜时长。
- **失败处理**：生成失败的任务会自动退回积分，并提示失败原因。
- **中途刷新页面**：已经提交的视频任务会记在项目里，重新打开项目后接着查进度；还没拿到结果的图片、关键帧和排队中的视频会退回积分。
- **超时**：调用模型接口默认 3 分钟超时（`UPSTREAM_TIMEOUT_MS` 可改），超时会返回 504 并退回积分。网络慢时建议调到 600000（10 分钟）。
- **下载结果**：Seedream 返回图片链接，后端再下载到本地；连接中途断开会从断点续传，最多重试 `DOWNLOAD_RETRIES` 次（默认 5）。视频同理。

## 功能一览

### 电商图片
- 批量上传商品图，每张图自动成为一个 SKU，可补充名称、卖点、到手价，主图会把这些文字排进画面
- 套图方案：图片类型多选 × 尺寸多选 × 每组张数，生成前显示总张数和预计积分
- 风格选择带示例图
- 7 个平台尺寸预设（淘宝/天猫、京东、详情页、小红书、抖音、亚马逊、店铺横幅）+ 自定义尺寸
- 结果按 SKU 分组，可筛选、全选本组；批量改尺寸 / 改风格 / 导出 / 删除

### 短剧生成
- 题材示例（都市逆袭、甜宠、悬疑），单集时长与镜头数可调
- 画面比例 9:16 / 16:9，画风（写实 / 电影感 / 动漫）
- 角色卡：姓名、身份、外形、主色、参考图
- 分镜可逐镜编辑景别、运镜、光线、时长、画面描述、台词；正式模式下「重写此镜」会结合前后镜头让模型重写
- 关键帧确认：确认 / 重画 / 改提示词重画 / 框选区域局部重绘；只有确认过的镜头会进入视频生成
- 视频模型不让用户选：配置了火山方舟就用 Seedance，只配置了可灵时用可灵。生成队列并发 2，时间轴预览，导出 MP4

### 界面与管理
- 左侧导航，首页有模块入口、最近项目、灵感画廊
- 暗色 + 青蓝紫渐变品牌色，浅色主题同样适配；默认跟随系统，右上角一键切换
- 项目自动保存；历史记录每次生成的内容和积分消耗

## 数据存储

| 运行环境 | 项目 / 历史 / 积分 | 上传的图片 | 生成的图片和视频 |
| --- | --- | --- | --- |
| 正式模式 | 本机 `data/store/` | 本机 `data/files/` | 本机 `data/files/` |
| 演示模式（浏览器） | `localStorage` | IndexedDB | 不产生文件 |
| Claude Artifact 内 | Claude 云端数据库 | Claude 文件存储 | 不产生文件 |

正式模式下所有数据都在 `data/` 文件夹里：**备份或换电脑，只要复制整个 `data` 文件夹**。从旧版本升级时，第一次打开会自动把浏览器里的项目、历史、积分和上传过的图片迁移到本机（只迁移一次）。

积分目前只是本地记账，还没有用户账号和真实计费。
